90PLUS — ГОТОВЫЙ КОД ДЛЯ TILDA

1. Открой Tilda → страницу.
2. Добавь блок «HTML-код» (категория «Другое»).
3. Открой HTML-код блока.
4. Скопируй ВСЁ содержимое файла 90PLUS_TILDA_CODE.txt.
5. Вставь в окно HTML-кода Tilda.
6. Сохрани блок и опубликуй страницу.

В код уже встроены загруженные фотографии, поэтому отдельно загружать эти 5 фото для демонстрационной версии не нужно.

Важно:
- Это самостоятельный визуальный макет внутри одного HTML-блока.
- Корзина и карточка товара работают как демонстрация, но не подключены к реальной оплате/складу.
- Для полноценного интернет-магазина потом подключим магазин Tilda, реальные товары, остатки, доставку и оплату.
- Если Tilda ограничит выполнение части JS в конкретном режиме блока, визуальная часть останется, а интерактивность можно перенести в Zero Block/магазин Tilda.
